# 🏋️ BodyBuzz Fitness & Training

A modern, responsive fitness website for a fictional fitness & training center in **Bhubaneswar**, featuring a bold dark neon-green design, smooth animations, and interactive UI.

## ✨ Features

* Responsive fitness website
* Training programs, trainers & membership plans
* Animated statistics and scroll-reveal effects
* Interactive hover and card animations
* Mobile navigation
* Testimonials section
* Contact form with backend validation
* MongoDB & SMTP email integration
* Google Maps integration

## 🛠️ Tech Stack

**Frontend:** HTML5, CSS3, JavaScript, Intersection Observer API, Font Awesome, Google Fonts

**Backend:** Node.js, Express.js, MongoDB, Mongoose, Nodemailer

## 📂 Sections

* Hero
* About
* Fitness Programs
* Trainers
* Testimonials
* Membership
* Contact & Location
