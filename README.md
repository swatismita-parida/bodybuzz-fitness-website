# 🏋️ BodyBuzz Fitness & Training

A modern, responsive, and fully animated fitness website designed for a fictional fitness & training center in **Bhubaneswar**.

BodyBuzz combines a bold dark theme, neon-green accents, smooth animations, interactive elements, and a premium fitness-focused user experience.

---

## 🌟 Project Objective

The objective of this project is to create an engaging and modern fitness website that provides users with information about training programs, trainers, membership plans, testimonials, and contact details.

The website is designed with a **dark neon-green fitness theme** and focuses on responsive design, smooth animations, and an attractive user interface.

---

## 🛠️ Technologies Used

* **HTML5** – Website structure and content
* **CSS3** – Styling, Flexbox, Grid, responsive design, gradients, and animations
* **JavaScript** – Interactivity and dynamic functionality
* **Intersection Observer API** – Scroll-based reveal animations
* **Font Awesome** – Icons
* **Google Fonts** – Archivo Black & Work Sans
* **Google Maps** – Location integration

## ✨ Interactive Features

### 1. Sticky Navigation Bar

The navigation bar remains visible while scrolling through the website.

### 2. Mobile Hamburger Menu

A responsive hamburger menu is provided for smaller screen sizes.

### 3. Smooth Scrolling

Navigation links smoothly scroll to their respective sections.

### 4. Animated Statistics

Hero section statistics use animated counters for:

* Members
* Trainers
* Classes

### 5. Scroll Reveal Animations

Sections and elements smoothly appear when they enter the viewport using the **Intersection Observer API**.

### 6. Hover Effects

Interactive hover effects are applied to:

* Buttons
* Program cards
* Trainer cards
* Images
* Icons
* Membership cards

### 7. Google Map

An embedded Google Map is included in the Contact section to display the fitness center location.

### 8. Featured Membership Animation

The featured membership plan includes a continuous glowing/pulse animation to make it stand out.

### 9. Back-to-Top Experience

Smooth scrolling allows users to quickly navigate through the website.
